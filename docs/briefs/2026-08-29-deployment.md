## 1. 目标

把这个站点部署到一个**学生和老师能在课堂上打开的公开地址**，并让每次 `main` 更新
自动发布。

## 2. 现状（实测数字，不是估计）

```
dist/index.html                     0.43 kB │ gzip:   0.31 kB
dist/assets/index-*.css             3.97 kB │ gzip:   1.30 kB
dist/assets/index-*.js          1,098.74 kB │ gzip: 302.24 kB
```

- JS 体积几乎全是 three.js。**后续会加 3D 模型资产**（见

  选型时请把这部分增量算进去
- 仓库当前**没有** `.github/`，没有任何 CI
- Node 要求 `>=20`，本地实测 v24.19.0

## 3. 决策点 #1：目标网络 —— 这条决定了其余一切

**我的假设：主要使用场景是中国大陆的校园网络。**

依据：全站中文、面向初中生物课堂、`Design.md` 通篇以中文课堂演示为目标。
**如果这个假设不成立，请先确认，因为它会推翻下面的选型结论。**

在这个假设下，"随便挂 GitHub Pages" 是不够的 —— 大陆访问 GitHub Pages / Vercel /
Cloudflare Pages 的延迟和可达性都不稳定，课堂上打不开就等于没部署。

请**实测**而不是照搬经验，至少覆盖：

| 候选 | 需要回答 |
|---|---|
| GitHub Pages | 大陆实测首屏耗时？是否间歇不可达？ |
| Cloudflare Pages | 同上 |
| Vercel / Netlify | 同上 |
| 腾讯云 COS / 阿里云 OSS + CDN | 是否需要备案？成本？操作复杂度？ |
| 其他国内静态托管 | 备案要求、免费额度、自动部署能力 |

**测法**：真机 + 大陆网络，冷缓存，记录首屏可交互时间；不要只跑 Lighthouse 本地分数。
如果拿不到校园网环境，至少用移动 / 联通 / 电信家宽各测一次，并注明测试条件。

**备案是硬门槛**：国内云 + 自定义域名通常需要 ICP 备案。请明确说明所选方案是否触发备案，
以及不备案时的可用形态（例如直接用云厂商分配的默认域名）。

## 4. 硬约束

- **`npm run verify` 是发布门禁。** typecheck + 127 个测试 + build，任何一项红都不许发布。
  不接受"先发上去再修"
- **不引入新的运行时依赖**。部署配置属于构建期/CI，不进 `dependencies`
- **不要提交任何密钥到仓库**。托管商 token 走 GitHub Actions Secrets
- **Vite `base`**：若选 GitHub Pages 的项目站（`user.github.io/Endocrine-Atlas/`），
  必须设 `base: '/Endocrine-Atlas/'`，否则资源 404。选自定义域名或根路径则不需要 ——
  **两种情况别搞混，本地 `npm run preview` 验证过再发**
- **保留可回滚能力**。说明怎么回退到上一个版本，以及需要多久
- 仓库根目录的 `Design.md`、参考图 `.jpg`、`Endocrine Atlas — Implementation Prompt.pdf`
  是项目文档，**不应该被发布到公网**。它们不在 `public/` 下，Vite 默认不会打包 ——
  确认一遍即可，别顺手把它们拷进产物

---

## 5. 交付物

1. **选型说明**（提交到 `docs/` 下）：候选对比 + 实测数字 + 明确推荐 + 被否掉的理由 +
   备案结论 + 成本
2. **CI 工作流**（`.github/workflows/`）：
   - push 到 `main` 触发
   - Node 20+
   - 跑 `npm ci && npm run verify`
   - 绿了才部署
   - PR 上只跑 `verify` 不部署
3. **可访问的公开 URL**
4. **README 增补一节**：部署地址、发布流程、回滚步骤

## 6. 验收标准

- [ ] 公开 URL 可访问，3D 场景正常渲染、可旋转、可点击腺体、可进出睾丸详情视图
- [ ] 大陆网络冷缓存实测首屏可交互 **< 3 秒**（写明测试网络与设备）
- [ ] 故意推一个会让测试失败的 commit，确认**部署被拦住**（这条要真做一次，不是口头保证）
- [ ] 回滚步骤被实际走通一次
- [ ] 资源路径正确，控制台零报错（注意 `base` 配错时表现为白屏 + 404）
- [ ] `docs/` 下的选型说明和 README 增补都在

---

## 7. 明确不做

- 不做后端、不做数据库、不做用户系统（`Design.md` §34）
- 不做多环境（staging / prod），一个生产环境足够
- 不做自定义域名，除非备案结论表明必须（若做，在选型说明里单列成本与工期）
- 不做监控告警 / 埋点分析 —— 这是课堂演示站，不是产品
- 不动应用代码。若发现必须改（例如 `base` 路径），只改构建配置那一处并说明原因
